## 🔧 Технические детали

### Структура таблицы
```python
# Инициализация
self.summary_table = QTableWidget(0, 13)  # 0 строк, 13 колонок

# Заголовки (динамические)
headers = ["Клиент"]
today = datetime.now().date()
for i in range(4):
    date_str = (today + timedelta(days=i)).strftime('%d.%m.%Y')
    headers.extend([
        f"{date_str}\nУв",      # Уведомления
        f"{date_str}\nПоз",     # Позиции
        f"{date_str}\nДМ"       # Коды ДМ
    ])

# Ширина колонок
self.summary_table.setColumnWidth(0, 120)      # Клиент
for i in range(1, 13):
    self.summary_table.setColumnWidth(i, 50)   # Метрики
```
