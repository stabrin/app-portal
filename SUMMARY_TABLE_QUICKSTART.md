# 🚀 БЫСТРЫЙ СТАРТ: Сводка поставок

## Что нужно знать

Таблица сводки показывает агрегированные данные по поставкам на 4 дня вперёд:
- **Клиент** - название клиента
- **Ув** - количество уведомлений о поставке
- **Поз** - количество позиций в товарах
- **ДМ** - количество кодов DataMatrix

## Где найти

1. **Запустите приложение**
   ```bash
   python desktop-app/run.py
   ```

2. **Логинитесь как администратор**

3. **Перейдите в "Управление уведомлениями"**

4. **Смотрите две таблицы:**
   - **Верхняя** - список всех уведомлений (детально)
   - **Нижняя** - сводка по дням (кратко)

## Как использовать сводку

### Быстрый обзор поставок
- Смотрите сводку, чтобы быстро понять объём работ на каждый день
- Каждая строка = один клиент
- Каждая колонка = день + тип данных

### Планирование работ
- **Сегодня (День 0)**: Сколько уведомлений нужно обработать сейчас
- **Завтра (День 1-3)**: Планируйте ресурсы на будущие дни

### Выявление проблем
- Если числа очень большие - может быть пик нагрузки
- Если много нулей - спокойный период

## Интерактивность

### Выбор строки в сводке
- Кликните на строку клиента
- Строка подсветится синим (#ADD8E6)

### Дополнительная информация
- Полную информацию по уведомлению смотрите в верхней таблице
- Для деталей дважды кликните на уведомление → откроется подробная страница

## Технические детали

### Обновление данных
- Данные загружаются при открытии страницы "Управление уведомлениями"
- Автоматическое обновление: при каждом открытии страницы

### Источник данных
- Таблица `ap_supply_notifications` в БД клиента
- Фильтр: только уведомления на ближайшие 4 дня
- Статусы: исключены "В работе" и "В архиве"

### Производительность
- Быстрая загрузка даже при большом объёме данных
- Оптимизирована для 1000+ уведомлений

## Часто задаваемые вопросы

**Q: Почему в сводке 4 дня, а не 7?**  
A: 4 дня достаточно для планирования. Это стандарт из старого интерфейса.

**Q: Можно ли отредактировать числа в сводке?**  
A: Нет, сводка только для чтения (read-only). Редактирование в верхней таблице.

**Q: Если нет данных, что будет?**  
A: Сводка будет пуста или покажет нули. Это нормально.

**Q: Как часто обновляются данные?**  
A: При каждом открытии страницы. Автоматического обновления нет.

**Q: Какие даты показываются?**  
A: Сегодня + 3 дня. Даты зависят от системного времени сервера.

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Сводка не загружается | Проверьте подключение к БД |
| Числа очень большие | Нормально, проверьте пик нагрузки |
| Сводка пуста | Проверьте статус уведомлений (не должны быть "В работе") |
| Даты неверные | Проверьте системное время сервера |
