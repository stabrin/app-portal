# Описание редактора макетов

Редактор макетов представляет собой визуальный инструмент для создания и изменения шаблонов этикеток. Он реализован с использованием `PySide6` и позволяет пользователям добавлять, перемещать и настраивать различные элементы на макете, такие как текст, штрихкоды и изображения.

Основная логика редактора сосредоточена в двух классах: `LabelEditorDialog` и `PrintableObjectItem`.

## Основные компоненты

### 1. `LabelEditorDialog`

Это основной класс, представляющий собой диалоговое окно редактора. Он включает в себя следующие элементы:

*   **Панель инструментов**: Содержит кнопки для добавления новых объектов на макет:
    *   Текст (из базы данных)
    *   Произвольный текст
    *   QR-код
    *   SSCC (штрихкод)
    *   DataMatrix (штрихкод)
    *   Изображение
*   **Холст (Canvas)**: Визуальное представление этикетки, реализованное с помощью `QGraphicsScene` и `QGraphicsView`. На этом холсте размещаются все объекты макета.
*   **Панель свойств**: Динамически отображает свойства выбранного на холсте объекта. Пользователь может изменять:
    *   Координаты (X, Y)
    *   Размеры (Ширина, Высота)
    *   Источник данных (например, поле из базы данных, произвольный текст, название изображения)
*   **Управление изображениями**: Кнопка для загрузки новых изображений в каталог, которые затем можно будет использовать в макетах.

### 2. `PrintableObjectItem`

Этот класс представляет собой отдельный объект на холсте (например, текстовое поле или штрихкод).

*   **Визуальное представление**: Каждый объект является прямоугольником (`QGraphicsRectItem`) с фоновым цветом, зависящим от его типа (текст, штрихкод, изображение), для легкого визуального различения.
*   **Интерактивность**: Объекты можно выделять и перемещать мышью прямо на холсте.
*   **Синхронизация данных**: При перемещении объекта его новые координаты (в миллиметрах) автоматически сохраняются в структуре данных макета. Панель свойств также немедленно обновляется, отражая новые значения.

## Процесс работы

1.  **Создание или редактирование**: Пользователь может создать новый макет, указав его название и размеры, или открыть для редактирования существующий.
2.  **Добавление объектов**: С помощью кнопок на панели инструментов пользователь добавляет на холст необходимые элементы.
3.  **Позиционирование**: Объекты можно перетаскивать мышью для точного позиционирования.
4.  **Настройка свойств**:
    *   Выделив объект, пользователь видит его свойства на панели справа.
    *   Для текстовых полей можно выбрать источник данных из предопределенного списка полей базы данных или ввести произвольный текст.
    *   Для штрихкодов выбирается тип и источник данных.
    *   Для изображений можно выбрать ранее загруженную картинку из каталога.
5.  **Сохранение**: После завершения редактирования пользователь нажимает кнопку "Сохранить", и обновленные данные макета (в формате JSON) сохраняются в базе данных.

## Техническая реализация

*   **Хранение данных**: Структура макета, включая все его объекты и их свойства, хранится в базе данных в виде JSON.
*   **Масштабирование**: Для преобразования координат из миллиметров (в данных) в пиксели (на холсте) используется коэффициент масштабирования (`canvas_scale`).
*   **Сигналы и слоты**: Взаимодействие между холстом (выбор и перемещение объектов) и панелью свойств (обновление полей) построено на механизме сигналов и слотов Qt. Например, сигнал `selectionChanged` от `QGraphicsScene` вызывает слот `_on_scene_selection_changed`, который обновляет панель свойств.
